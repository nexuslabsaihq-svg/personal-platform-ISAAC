## 🚀 Stack Tecnológico

- **Framework:** [React 18](https://react.dev/)
- **Bundler & Tooling:** [Vite 5](https://vitejs.dev/)
- **Estilos:** [Tailwind CSS 3](https://tailwindcss.com/)
- **Motor de Animaciones:** [Framer Motion](https://www.framer.com/motion/)
- **Iconografía:** [Lucide React](https://lucide.dev/)
- **Despliegue & CI/CD:** [Vercel](https://vercel.com/)

---

## 🎨 Sistema de Diseño

- **Fondo Base:** `#0B0E14`
- **Superficie / Cards:** `#131722`
- **Bordes:** `#1F2430` (opacidad 40%-60%)
- **Texto Principal:** `#E8EAED`
- **Texto Secundario:** `#8B92A5`
- **Acento Primario (Acción/Hover):** `#5B8DEF`
- **Acento Secundario (Logros/Cifras):** `#D4AF37`
- **Tipografía:**
  - *Sora:* Títulos y encabezados
  - *Inter:* Cuerpo de texto y párrafos
  - *JetBrains Mono:* Monogramas, badges y etiquetas de código

## 🛠️ Instalación y Uso Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/nexuslabsaihq-svg/personal-platform-ISAAC.git
cd personal-platform-ISAAC

# 2. Instalar dependencias
npm install

# 3. Iniciar entorno de desarrollo
npm run dev

# 4. Compilar para producción
npm run build
```
