# Finance Nexus Documentation Boundary

This folder contains a safe index and context map for the Finance Nexus references supplied to this portfolio project.

It is intentionally separate from `docs/ai/`:

- `docs/ai/` explains how agents work on this portfolio.
- `docs/finance-nexus/` explains how to locate and interpret Finance Nexus context.

Do not add original Finance Nexus documents, credentials, account identifiers, private contact data, prompts, commercially sensitive prices, projections, legal drafts, or Firestore rules to this public portfolio repository.

For an actual Finance Nexus development task, use the private canonical document store and its own code repository.
